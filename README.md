# EDITORS.IPAM — IPAM Network Address Manager

**Wiki:** [Documentation/README.md](Documentation/README.md) — principles, architecture, delivery.

IP Address Management (IPAM) Softapp: manage facility IP address spaces, IPv4/IPv6 subnets, CIDR netmasks, DHCP pools, gateway assignments, and VLAN bindings.

| | |
|---|---|
| **Opens** | the OS shell (Design → Network & Topology), or `index.html` standalone |
| **Build** | none — plain web files; `npm test` |
| **Ships** | baked into WEB.Frontend-Assets (`up-stack.sh WEB.Frontend-Assets`), served at `:8080/Softapps/EDITORS/EDITORS.IPAM/` |
